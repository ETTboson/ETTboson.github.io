# Ningyuan Wu's personal homepage

An English academic homepage prepared for `https://ettboson.github.io/`.
Plain HTML, CSS, and a small navigation enhancement. No build step or runtime dependencies.

## Edit

- `index.html`: About Me, Research Interests, Education, Research & Projects, Experience, Awards, and Beyond Research.
- `styles.css`: page layout and responsive styles.
- `tokens.css`: colors and type tokens.
- `assets/`: project figures, the cat portrait, table tennis photographs, and local fonts.

## Preview locally

Run a static web server in this directory, for example `python -m http.server 4173`, and open `http://localhost:4173`.

## Publish to GitHub Pages

1. Review the full page before uploading.
2. In the ETTboson account, create the public repository `ETTboson.github.io`.
3. Upload the contents of this directory to the repository root, preserving the `assets` folder. Commit only after reviewing the final files and commit message.
4. In repository Settings, open Pages. Choose **Deploy from a branch**, then `main` and `/ (root)`, and save.
5. Wait for GitHub Pages to finish its deployment. The expected address is `https://ettboson.github.io/`.

Publishing, uploading, and final confirmation are performed manually by the owner.

Official instructions: https://docs.github.com/en/pages/getting-started-with-github-pages/creating-a-github-pages-site
